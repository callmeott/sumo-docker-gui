Launch / Restart restarts the program with the given arguments (takes a few seconds; the window reloads). Open window just views the running instance. Your data folder is mounted at /data. netedit and sumo-gui are the only windowed SUMO programs — the rest (netconvert, duarouter, …) are command-line: docker compose exec sumo-gui bash.
